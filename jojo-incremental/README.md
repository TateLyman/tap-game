# Bizarre Legacy

A free, fan-made browser incremental RPG inspired by *JoJo's Bizarre Adventure*. No backend is required; all progress is stored locally in the browser.

## Current playable systems

- Active click combat, critical hits, combo scaling and passive party DPS
- 9 sequential Parts / worlds with 30 encounters each and distinct bosses
- Character roster, party building, leveling, roles and cross-character synergies
- Stand Arrows, Stand collecting, Stand leveling and challenge-gated evolution paths
- Active skills / ultimates, time-stop style effects, defense break and automation
- Multiple currencies, Fate events, rare relic drops and achievement tracking
- Rebirth / Joestar Legacy prestige
- Quests and permanent unlock tracking
- Offline progress, autosave, manual export/import and hard reset
- Responsive desktop/mobile UI and original synthesized sound effects

## Notes

This is a non-commercial fan project. It does not bundle copyrighted anime/manga art, music, voice clips, or sound assets. Visuals are original CSS/UI treatment and synthesized browser audio.

## Local run

Open `index.html` directly or serve the folder with any static web server.
